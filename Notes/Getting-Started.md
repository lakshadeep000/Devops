# How to Take Notes Here

This folder is your **Obsidian vault**. Keep your own notes here, separate from the plan.

#getting-started #notes

---

## Recommended Structure

```
📁 Default Project/
├── README.md              ← Dashboard (start here)
├── Plan/                  ← The zero-to-hero plan (don't edit, just follow)
├── Notes/                 ← YOUR learning notes live here (daily logs, concept notes)
├── Cheatsheets/           ← Reference sheets for commands & tools
├── Templates/             ← Copy these when making new notes
└── Scripts/               ← Your lab scripts & configs (optional)
```

## Folder-by-Folder

| Folder | What goes here |
|--------|----------------|
| `Plan/` | The learning plan. Read-only — treat it as your syllabus. |
| `Notes/` | Your daily/module logs and concept notes. Name them clearly: `L1-M1-Linux.md`, `Networking-Notes.md`. |
| `Cheatsheets/` | Reference sheets: every command/tool with argument breakdowns. One per topic: `Linux-Cheat-Sheet.md`, `Docker-Cheatsheet.md`. Link them from your notes with `[[Cheatsheets/...]]`. |
| `Templates/` | Copy the template contents into a new note. Or set it in Obsidian: *Settings → Templates* → template folder location. |
| `Scripts/` | Practical files: `.sh`, `.py`, `.yml`, `Dockerfile`s, Terraform configs. |

## Obsidian Tips

1. **Open as vault:** Obsidian → *Open folder as vault* → this folder.
2. **Wikilinks:** type `[[` to link notes (e.g., `[[Day-05-Linux-Permissions]]`).
3. **Tags:** add `#docker` `#linux` etc. to search/filter later.
4. **Daily Logs:** create one per day from the [[Templates/Daily-Log-Template|Daily Log template]].
5. **Graph View:** open the graph to see how your knowledge is connecting.
6. **Core plugin "Templates":** enable it so the template shortcuts work.
7. **Sync:** point your phone/other devices at the same folder for free, or use Obsidian Sync.

## Golden Practices

- Always take a note the **same day** — even 5 bullet points.
- Paste the exact commands you ran (so future-you can rerun them).
- When you fix an error, write the fix down. Errors repeated = learning compounded.
- Review every Sunday: re-read the week's logs, fix gaps.
